Azure App Setup Steps
1. Go to portal.azure.com on your desktop and sign in with your Carrington account.
2. Search for "App registrations" and click New registration.
3. Name it "ST300 Grading App", set Redirect URI to Single-page application (SPA) and enter the tiiny.host URL of this app.
4. Click Register. Copy the Application (client) ID and paste it above.
5. Under API permissions, add Microsoft Graph > Files.ReadWrite.
6. Done. Come back here and save settings.
